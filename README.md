# Expense Tracker Dashboard

A full-stack Expense Tracker Dashboard that helps users add, manage, edit, delete, and track their daily expenses through a clean and aesthetic interface.

## Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- View all recorded expenses
- Categorize expenses
- Track total expenses
- Instant success and error messages
- Responsive and user-friendly interface
- Data stored using MongoDB
- REST API for expense management

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Axios
- React Icons

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv
